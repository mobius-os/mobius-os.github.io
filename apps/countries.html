Countries Been

v1.0.0 by mobius-os MIT Source ★ 0 updated 2026-05-30

What it does

Tap a 3D globe to mark the countries you've visited. See them glow on the map, in a list, and as a count.

Install

Open the App Store mini-app in your Möbius shell and paste: 

https://raw.githubusercontent.com/mobius-os/app-countries/main/mobius.json

Möbius shows the requested permissions, then installs.

Manifest

The live mobius.json:

{
  "id": "countries",
  "name": "Countries Been",
  "version": "1.0.0",
  "description": "Tap a 3D globe to mark the countries you've visited. See them glow on the map, in a list, and as a count.",
  "author": "mobius-os",
  "license": "MIT",
  "homepage": "https://github.com/mobius-os/app-countries",
  "entry": "index.jsx",
  "offline_capable": true,
  "permissions": {
    "cross_app_access": "none",
    "share_with_apps": "none"
  },
  "storage_seeds": {
    "visited.json": [],
    "countries.geo.json": "countries.geo.json"
  },
  "runtime": {
    "imports": [
      "react",
      "react-dom"
    ],
    "esm_deps": [
      "d3-geo"
    ]
  }
}
