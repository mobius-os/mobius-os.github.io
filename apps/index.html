Workout

v2.3.4

Chat-first embedded-agent training log. Tell the Workout agent what you did — "deadlift 3x5 at 120kg, swam 40 minutes" — and it builds a current session draft, asks for required missing details, then commits on Finish session. Uses the real Möbius embedded chat with model picker, plus a per-exercise drill-down (estimated-1RM/pace trend, records, set-records, full history), strength PRs, cardio bests, weekly volume, category stats, and a streak heatmap.

Build your own

Any public repo with a valid mobius.json is installable via paste-a-URL in the App Store mini-app. Apps don't need to be on this curated list to be shared — host the manifest anywhere (GitHub, Codeberg, GitLab, a personal site) and the URL is the install link. See Build a Möbius app for the manifest schema and the storage / cron contracts.
