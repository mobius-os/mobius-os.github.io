News

v1.5.0 by mobius-os MIT Source ★ 0 updated 2026-05-30

What it does

Daily AI-curated news digest. Customize what to search for and the delivery schedule from inside the app.

Install

Open the App Store mini-app in your Möbius shell and paste: 

https://raw.githubusercontent.com/mobius-os/app-news/main/mobius.json

Möbius shows the requested permissions and the cron schedule, then installs.

Manifest

The live mobius.json:

{
  "id": "news",
  "name": "News",
  "version": "1.5.0",
  "description": "Daily AI-curated news digest. Customize what to search for and the delivery schedule from inside the app.",
  "author": "mobius-os",
  "license": "MIT",
  "homepage": "https://github.com/mobius-os/app-news",
  "icon": "icon.png",
  "entry": "index.jsx",
  "permissions": {
    "cross_app_access": "none",
    "share_with_apps": "none"
  },
  "storage_seeds": {
    "system-prompt.md": "system-prompt.md",
    "topics.txt": "topics.txt",
    "schedule.json": {
      "hour": 10,
      "minute": 0
    }
  },
  "schedule": {
    "default": "0 10 * * *",
    "user_configurable": true,
    "job": "fetch.sh"
  },
  "runtime": {
    "imports": [
      "react",
      "react-dom"
    ],
    "esm_deps": [
      "dompurify"
    ]
  }
}
