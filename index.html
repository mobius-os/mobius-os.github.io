Open-source personal AI

Community intelligence you can run, inspect, and improve.

Möbius is a self-hosted human-agent improvement system. It remembers what matters, reflects across your work, builds apps with you, and can publish changes back to GitHub so the platform and its community apps keep getting better.

The internet made software communal. AI can make it recursive: people improve agents, agents improve tools, and the tools make the next improvement easier. Möbius keeps that loop open, private, and hackable.

Bring your own agents.

Use your existing ChatGPT or Claude plan. Möbius gives the agents a place to work: memory, files, apps, schedules, and a browser-native interface that can also feel like a phone app.

Own the harness.

The platform is open source. You can change the chat, the runtime, the app store, or any app inside it. Agents can help implement those changes and push them through GitHub.

Spend fewer tokens.

Reflection and advanced memory help Möbius reuse what it has already learned instead of rediscovering your context every time. The system gets more useful as it gets to know your work.

The recursive loop

Ask for a workflow, get an app. Use it, reflect on it, and let agents improve the app or the harness itself. When the change is useful, publish it. Möbius is designed for private self-hosting and for community evolution at the same time.

  1. TalkDescribe what you want, from a note workflow to a new app.
  2. BuildAgents edit code, wire storage, and run the experience in Möbius.
  3. RememberReflection turns usage into durable context and better defaults.
  4. SharePush changes to GitHub or install apps from the community catalog.

Everything is part of the system.

Apps are public repos with a mobius.json manifest. The runtime handles install, storage, scheduled jobs, theme tokens, and app navigation, so an agent or a human can focus on the actual interface.
