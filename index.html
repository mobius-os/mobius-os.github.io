A personal AI agent that adapts to you and builds your apps.

Möbius is a personal AI agent you run yourself. It learns what matters to you and gets more helpful the more you use it, and it builds and hosts the apps you ask for. Use it in your browser or install it on your phone (PWA). It runs on your existing ChatGPT or Claude plan, and your data stays on your own server.

Install Möbius Read the spec

You ask, it builds.

You do not need to write any code. Describe what you want and Möbius builds the app for you, runs it right next to the chat, and keeps it there. A budget tracker, a workout log, a trip planner, whatever fits your day. You can ask it to change Möbius itself too, its look or how it works, and it updates on the spot. It even builds the thing it runs in, then uses that to build the next one. That loop is the Möbius strip it is named after.

It learns and improves.

Möbius remembers what matters to you and gets more useful the more you use it. Every night, while you sleep, it reviews the day, tidies what it has learned, and looks for things worth building next. Over time it shapes itself around how you actually live and work.

Build your own

An app is a public git repo with a mobius.json manifest and a single JSX file. The runtime handles install, storage, scheduled jobs, and updates, so the app is mostly its own UI. Any repo with a valid manifest installs by pasting its URL, so an app doesn't have to live in this catalog to be shared. The manifest URL is the install link. The build spec covers the manifest schema, the storage API, the cron contract, and the theme tokens.
