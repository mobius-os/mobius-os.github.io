Build a Möbius app

The contract is small: a public repo with a valid mobius.json and a single-file index.jsx. That's enough to be installable by any Möbius user via paste-a-URL.

The contract

  • A public git repo (GitHub is easiest; raw.githubusercontent.com is the fetch path).
  • A mobius.json at the repo root that validates against the JSON Schema. See the manifest spec for field reference.
  • An index.jsx exporting a default React component. The Möbius shell renders it inside app-frame.html; theme tokens and storage helpers are available on window.
  • Optional: icon.png (any size; server resizes to 1024).

Submitting for curation

Two paths:

  1. Just share the URL. No PR required. Anyone can install any public manifest via the App Store's paste-a-URL field. This is the path for personal apps and experiments.
  2. Get listed on the catalog. Open a PR against the curated list inside app-store/index.jsx. Curated apps show up on the front page of the App Store and on mobius-os.github.io/apps. The bar: works as advertised, no obvious abuse vectors, and a short description.

Code style

  • Single-file JSX. Everything in index.jsx. Split helper functions, but no separate component files for v1 of the spec.
  • Theme tokens. Read from CSS custom properties (--bg, --surface, --accent, --text, --muted, --border). Don't hard-code colors — users can theme the shell.
  • Storage API. Read/write JSON at /api/storage/apps/<slug>/<path>. Treat storage as your source of truth; never assume in-memory state survives a rebuild.
  • Cron jobs. If your app declares a schedule, ship the script at the path declared by job. The runtime copies it to /data/apps/<slug>/ and runs it non-interactively.
  • No build step. Möbius transpiles JSX in-browser. Ship source, not bundles.

Storage API patterns

// Read a JSON blob (returns the parsed value, or null on 404)
const cfg = await fetch(`/api/storage/apps/${slug}/config.json`, {
  headers: { Authorization: `Bearer ${token}` }
}).then(r => r.ok ? r.json() : null);

// Write a JSON blob
await fetch(`/api/storage/apps/${slug}/config.json`, {
  method: 'PUT',
  headers: {
    Authorization: `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(cfg)
});

Where to ask

Open an issue on the main Möbius repo for runtime questions; on your own app repo for app-specific bugs. The spec lives under /spec.
